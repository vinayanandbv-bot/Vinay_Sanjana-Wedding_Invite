# 👑 The Royal E-Wedding Invitation

A simplistic, stately royal wedding e-invitation featuring an authentic pull-down scroll mechanism with touch and mouse drag physics, classical Raag Yaman wedding melody, live countdown, and calendar integration.

Designed to be hosted on **GitHub Pages**.

---

## ✨ Features

- 📜 **Physical Pull-Down Scroll**:
  - Touch and mouse gesture drag physics.
  - Silk cord intertwined with gold thread and weighted royal tassel.
  - Understated small-caps instruction: `❖ PULL THE GOLDEN THREAD TO UNROLL ❖`.
  - Smooth unroll animation revealing museum-grade double-ruled gold leaf parchment.
- 🎶 **Classical Royal Wedding Melody (Web Audio API)**:
  - Composed in classical **Raag Yaman / Kalyan Court Romance** with warm acoustic tanpura/cello drone pedal harmonics and serene flute/harp phrasing.
  - Zero external MP3 dependencies; 100% reliable offline and on GitHub Pages.
- ⏳ **Live Countdown Timer**:
  - Days, Hours, Minutes, and Seconds counting down to November 28, 2026.
- 🏰 **Ceremony & Venue Details**:
  - Placeholders for Bride, Groom, and Parents.
  - 📍 View on Google Maps.
  - 📋 One-click "Copy Venue Address" with toast feedback.
  - 📅 "Add to Google Calendar" button.
  - 💾 "Apple / Outlook (.ics)" instant download.
- 👔 **The Wedding Festivities (Itinerary)**:
  - Friday, Nov 27: The Sangeet & Mehendi Celebration.
  - Saturday, Nov 28: The Haldi Ceremony.
  - Saturday, Nov 28: Baraat, Varmala & Holy Pheras.
  - Saturday, Nov 28: The Grand Royal Reception.

## 🚀 How to Host on GitHub Pages

1. **Create an empty repository on GitHub**:
   - Go to [github.com/new](https://github.com/new) and name it (e.g. `wedding-invitation`).
   - Leave it **Public** and do not initialize with a README.
2. **Push your code**:
   ```bash
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
   git branch -M main
   git push -u origin main
   ```
3. **Turn on GitHub Pages**:
   - In your GitHub repo, go to **Settings** > **Pages**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - Live URL: `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
