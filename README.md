# Sanjana & Vinayanand — Wedding Invitation

An exact, 100% pixel-perfect and functionally identical replica of the bespoke wedding invitation from `https://sanjana-vinayanand-invitation.lovable.app/`.

## ✨ Features & Polish
- **Interactive 3D Envelope Opening**:
  - Realistic textured ivory stationery and envelope folds with gold foil highlights.
  - Burgundy wax seal embossed with the couple's concentric monogram (`V & S`).
  - Smooth 3D flap unsealing with physics-based release animation (`2650ms` sequence).
  - Emerging monogram card gracefully sliding out of the envelope.
- **Revealed Invitation Sheet**:
  - Four ornate gold filigree corner ornaments.
  - Elegant serif typography (`Cormorant Garamond`), script ampersands (`Italianno`), and clean sans-serif accents (`Jost`).
  - "With the blessings of our families" heading and couple announcement.
  - Interactive "Get Directions" link directly connecting to Aditya Kalyana Mantapa on Google Maps.
  - Timeline cards for the Wedding Ceremony and Wedding Reception.
  - Interactive "Add to Calendar" dropdown with dynamic Google Calendar generation and RFC 5545 `.ics` file downloads (for Apple Calendar, Microsoft Outlook, and mobile devices).
  - Real-time countdown timer tracking days, hours, minutes, and seconds until 20 November 2026.
  - Native Web Share API integration with automatic fallback to clipboard copy.
  - "Back to the envelope" smooth scroll-and-reset button with keyboard focus restoration.

## 🚀 How to Run Locally
You can double-click `index.html` to open it directly in any modern browser, or run a local static server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
